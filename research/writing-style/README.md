# Writing-style evidence

Primary-source research for a future revision of the `writing-style` skill.

This folder separates collected evidence from the synthesis and any later changes to the published skill.

## Contents

- [Standards and research](standards-and-research.md) covers ISO and DITA standards, government guidance, and original experiments on prior knowledge, context, coherence, relevance, and structure.
- [Company style guides](company-style-guides.md) compares first-party guidance and examples from Google, Microsoft, GitHub, Red Hat, IBM, Apple, AWS, and Stripe.
- [Audience archetypes](audience-archetypes.md) compares DITA, Diátaxis, company audience models, release-note guidance, and names for the missing experienced product user.
- [Synthesis and next steps](synthesis.md) assesses the current skill and separates evidence-backed changes from design choices.
